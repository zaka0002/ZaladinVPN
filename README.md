# ZaladinVPN

VPN et DNS gratuits pour Android TV (et téléphones).

- **VPN** : toute la TV passe par Cloudflare WARP (gratuit, sans compte). L'adresse IP est masquée.
- **DNS** : seul le DNS change (AdGuard, AdGuard Famille, Cloudflare, Cloudflare Famille, Quad9, Google).
- Un seul à la fois. Démarrage automatique quand la TV s'allume.

Téléchargement : https://github.com/zaka0002/ZaladinVPN/releases/latest/download/ZaladinVPN.apk
